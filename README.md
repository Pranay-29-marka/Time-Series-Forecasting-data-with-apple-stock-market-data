# Time-Series-Forecasting-data-with-apple-stock-market-data
Utilized Pandas for comprehensive data cleaning and preprocessing of stock market data, performing Exploratory Data Analysis (EDA) with Matplotlib to uncover trends, establishing a robust foundation for analysis and modeling.
Developed and implemented time-series forecasting models (ARIMA, SARIMA) in Python to accurately predict Apple stock price movements, achieving reliable future value predictions rigorously evaluated using RMSE, MAE, and MSE.
Innovatively leveraged Meta AI to extract advanced model interpretations, key insights, seasonal patterns, and trend directions from model outputs, transforming complex data into understandable narratives.
Designed and built an AI-assisted decision-making dashboard in Power BI to consolidate model future predictions with Meta AI-generated insights, seasonal patterns, and trend directions, enabling stakeholders to make strategic, data-informed decisions.
Tech Stack: Python (Pandas, Matplotlib, Scikit-learn), Power BI, Jupyter
